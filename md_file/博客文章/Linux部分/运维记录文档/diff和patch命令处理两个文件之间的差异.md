## 差异处理diff-patch



```shell
-- diff命令
-- 标准格式输出差异
diff -u file1 file2

-- 并列格式输出差异对比
diff -u file1 file2

-- 只报告文件是否不同，不显示具体差异内容
diff -q file1 file2


-- patch
-- 先生成补丁包
diff -uN b.txt a.txt  > change.txt

-- 应用补丁文件
patch b.txt < change.txt






```





| `-r`                | ‌**递归**‌比较目录下的所有子文件 | 比较两个文件夹整体差异                                       |
| ------------------- | ------------------------------ | ------------------------------------------------------------ |
| `-i`                | ‌**忽略大小写**‌                 | 比较不区分大小写的文本                                       |
| `-b`                | ‌**忽略空格数量变化**‌           | 代码格式化导致的空格差异                                     |
| `-w`                | ‌**忽略所有空格**‌               | 忽略缩进、Tab等空白字符差异                                  |
| `-B`                | ‌**忽略空白行**‌                 | 忽略空行的增删                                               |
| `-E`                | ‌**忽略 Tab 扩展差异**‌          | 处理 Tab 和空格混用问题                                      |
| `-N`                | ‌**将缺失文件视为空文件**‌       | 比较目录时，如果一个文件只在其中一个目录存在，将其与空文件比较（常用于生成完整补丁） |
| `--exclude=PATTERN` | ‌**排除特定文件**‌               | 比较目录时忽略 `.git`, `*.log` 等                            |
| `--color=auto`      | ‌**彩色输出**‌                   | 高亮显示差异部分（需终端支持）                               |
