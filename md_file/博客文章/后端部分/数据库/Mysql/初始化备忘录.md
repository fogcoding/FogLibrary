## 初始化备忘录



#### 设置时区为东八区

```sql
show variables like '%time_zone%';
select now();
set global time_zone = '+8:00';
flush privileges;
```

#### Windows下安装

```mysql
-- 安装服务并制定配置文件
mysqld install mysql --default-files=d:\datacore\xxxxxxx
-- 初始化基础文件
mysqld --initialize
-- 启动服务
net start mysql
-- 修改密码
SET PASSWORD FOR 'root'@'localhost' = PASSWORD('123456');

```



## Linux下安装

* 准备工作

```sql
-- 首先需要一个干净的系统环境，现在云服务器自己安装了各自支持的发行版，需要将其卸载干净，才能不影响自己安装的mysql
-- centos下，rpm查看有哪些安装过的软件
rpm -qa | grep mariadb

-- 强制卸载部分不需要的程序
rpm -e --nodeps mariadb-libs-5.5.37-1.el7_0.x86_64

--当原本版本的程序卸载干净后，可以开始安装自己的mysql了
```

修改加密规则
Mysql8.0之前的版本中，加密规则是mysql_native_password，而在Mysql8之后,加密规则是caching_sha2_password
当使用低版本客户端登陆时会报错，因此有两种解决方式：1、升级客户端；2、更改Mysql加密方式

## [mysqld]  配置 mysql_native_password=ON
--修改密码验证方式
alter user 'root'@'localhost' identified with mysql_native_password;
--修改实际密码
alter user 'root'@'localhost' identified by '123456';

-- 修改root远程连接权限
update user set host='%' where user='root' and host='localhost';
-- 刷新权限
flush privileges;

-- 当以上的步骤完成后，避免被黑客攻击，修改成复杂得密码
alter user 'root'@'%' identified by '1q2w#E$R7u8i(O)P';

-- 刷新权限
flush privileges;

-- ############################ MySQL 主从复制部分#############################
-- 主服务器创建权限账户，并授予复制权限
CREATE USER 'sync'@'%' IDENTIFIED BY 'sync3306';
GRANT REPLICATION SLAVE ON *.* TO 'sync'@'%';

-- 创建用户密码的时候，需要设置密码加密格式，否则会无法连接
alter user 'sync'@'localhost' identified with mysql_native_password by 'sync3306';
-- 对于备份的机器，用户名密码用默认的加密插件，不然连不上
alter user 'sync'@'localhost' identified with caching_sha2_password by 'sync3306';


CREATE USER 'sync'@'localhost' IDENTIFIED BY 'sync3306';

GRANT REPLICATION SLAVE ON *.* TO 'sync'@'localhost';


-- 查看主服务器的二进制日志文件名和位置
SHOW MASTER STATUS;
-- 在8.4版本不再支持，被SHOW BINARY LOG STATUS.取代

-- 从服务器上执行以下命令，连接到主服务器
CHANGE MASTER TO MASTER_HOST='8.129.10.47:3306', MASTER_USER='sync',MASTER_PORT=3307,MASTER_PASSWORD='sync3306',MASTER_LOG_FILE='mysql-bin.000001',MASTER_LOG_POS=683;

-- 特别需要注意：caching_sha2_password密码加密方式以后，要配合设置SOURCE_SSL=1，否则会连不上
CHANGE REPLICATION SOURCE TO SOURCE_HOST='8.129.10.47', SOURCE_USER='sync',SOURCE_PORT=3306,SOURCE_PASSWORD='sync3306',SOURCE_SSL=1,SOURCE_LOG_FILE='mysql-bin.000001',SOURCE_LOG_POS=1826;

master_host_name：主服务器的IP地址或主机名。
password：从服务器账户的密码。
recorded_log_file_name：在步骤2中记录的主服务器的二进制日志文件名。
recorded_log_position：在步骤2中记录的主服务器的二进制日志位置。

--启动从服务器复制
START SLAVE;
-- 8.4应该用 STRAT REPLICA

--检查从服务器复制进程是否已启动
SHOW SLAVE STATUS\G
-- 8.4版本应该用SHOW REPLICA STATUS

-- 如果Slave_IO_Running和Slave_SQL_Running的值都为“YES”，则表示从服务器已经成功连接到主服务器并开始复制

-- 如果需要停止主从服务复制的功能，使用以下命令：
stop slave;
-- 8.4应该用 stop REPLICA 
-- 若搭建主从复制的过程出错，则需要清理掉之前的配置，还需要执行以下命令：
reset slave all;
-- 8.4应该用reset REPLICA all;


--
-- ############################ MySQL 主从复制部分#############################



-- 若是忘记了root密码，重置root密码
-- [mysqld]    skip-grant-tables 
-- 直接将密码改成空，就可以mysql命令连接时回车直接进入，再改密码
-- 当执行命令时，提示skip-grant-tables,则执行flush privileges一遍，即可再次执行语句成功
