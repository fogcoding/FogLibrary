## 尝试优化方式

通过git log命令，逐步过滤和筛选对应的提交内容，提交人，变动范围。



```shell

-- 通过命令过滤关键字
git log -v  --oneline  --grep  fix

-- 通过提交hashid,过滤变动文件
-- dos
git show 82c85dc291 --oneline | findstr "diff --git"

--linux
git show 82c85dc291 --oneline | grep "diff --git"


```
